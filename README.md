# 🍎 苹果种植知识模型系统 v2.2

> 基于BBCH物候期编码的苹果全生长周期数字化管理系统，覆盖品种建模、种植计划、数据采集、农事派工、作业记录、成本分析的完整业务闭环。

---

## 📖 项目简介

本系统是一套面向苹果种植园区的轻量化知识管理工具，以**生长模型**为核心，围绕**品种特性**和**物候期**组织全部数据，实现从"建模 → 计划 → 采集 → 派工 → 记录 → 分析"的完整数字化种植管理流程。

### 核心理念

- **品种驱动**：7个预置品种（秦脆、瑞雪、福布拉斯、蜜脆、富士冠军、红思尼克、爱妃），指标参考范围根据品种自动适配
- **BBCH编码**：全部指标和农事作业绑定BBCH物候期编码（00-99），实现精准时序管理
- **阈值预警**：四级状态判定（🟢正常 → 🟡预警 → 🟠警报 → 🔴危险），实时触发调整措施建议
- **成本闭环**：计划预算 → 派工执行 → 作业记录 → 成本回填 → 对比分析

## 📋 功能模块

### 1. 🌳 生长模型管理

系统核心模块，为每个品种建立完整的生长知识模型。

**基础信息**
- 品种（秦脆/瑞雪/福布拉斯/蜜脆/富士冠军/红思尼克/爱妃）
- 苗龄、砧木类型与品种、栽培密度、支架模式

**自定义物候期**
- 8个默认阶段：休眠期 → 萌芽现蕾期 → 开花结果期 → 幼果春梢生长期 → 花芽分化及果实膨大期 → 着色成熟采收期 → 采后恢复期 → 落叶期
- 每阶段绑定BBCH编码范围和时间窗口
- 可视化条形时间轴

**指标体系**（70+预置指标，按4大面板分类）

| 面板 | 子分类示例 | 指标数 |
|------|-----------|-------|
| 🌳 生育模型管理 | 整株-结构、花果、叶片、果实品质、产量 | 30+ |
| 🌤 生育环境模型管理 | 温度、水分、光照、风速、土壤 | 20+ |
| 🐛 病虫草害模型管理 | 病害-枝干/叶片/果实、虫害、草害 | 15+ |
| 🔧 种植管理模型管理 | 农事作业（30项预置，含成本预填） | 30 |

- **品种自动适配**：指标参考范围根据品种自动调整（如秦脆苦痘病风险=极高，蜜脆钙需求=最高）
- **树龄自动适配**：树高、干径、分枝量等指标根据苗龄自动匹配
- **分组折叠**：每个面板内按子分类分组，支持折叠/展开
- **全局搜索**：跨面板模糊搜索，搜索结果保留分组标题

**农事作业库**（30项预置）
- 涵盖冬季修剪、清园、疏花疏果、套袋、水肥管理、植保防治、采收等全流程
- 每项作业预填参考成本（物料/人工/设备 元/亩）
- 绑定BBCH物候期和作业标准

**阈值设置**
- 每个指标支持四级阈值：适宜区间 → 预警阈值 → 行动阈值 → 危害阈值
- 输入实测值时实时显示状态图标

---

### 2. 📋 种植计划管理

基于生长模型制定年度种植计划。

- 关联生长模型，自动加载该品种的指标和作业
- 支持地块、面积、密度、株行距、目标产量等信息
- **计划作业管理**：
  - 从模型作业库中选择或手动新增
  - 每项作业配置：状态、日期、负责人、BBCH范围
  - **资源配置**：人工（人数×技能×工价×天数）、物资（名称/规格/数量/单价）
  - 自动计算预算汇总
- **一键生成派工单**：计划作业直接转化为派工单
- **执行生成记录**：计划一键执行为种植记录

---

### 3. 📊 数据采集（v2.2新增）

打通"计划 → 采集 → 预警 → 调整 → 派工"的监测链路。

**采集流程**
1. 选择关联计划和当前物候期
2. 系统自动加载该物候期适用的全部指标
3. 录入实测值，实时显示四级状态判定
4. 异常指标自动推荐调整措施

**状态概览**
- 五张卡片：🟢正常 / 🟡预警 / 🟠警报 / 🔴危险 / 已采集数
- 支持按状态筛选指标明细

**调整措施建议**
- 异常指标自动匹配预设措施映射（16个指标→措施映射）
- 措施关联具体农事作业
- 支持接受/拒绝/生成派工单的完整流转

**示例**
```
采集数据：早期落叶病病叶率 = 6.2%（阈值 <5%）
  → 🟠 警报
  → 自动建议：喷施代森锰锌+戊唑醇 → 关联作业"保叶防治"
  → 接受 → 生成派工单
```

---

### 4. 📋 派工单管理

将计划作业或采集异常转化为现场执行指令。

**派工单结构**
- 基本信息：任务描述、签发日期、地点、负责人、状态
- 决策因素：天气影响、人员安排、紧急程度、资源调配
- 人员配置：人数、工时、人员名单
- 工具/物资/设备配置
- 执行情况：实际开始/结束、完成度、实际面积
- 来源追溯：可追溯到计划作业或数据采集

**状态流转**
```
待执行 → 执行中 → 已完成
```

**一键生成作业记录**：派工单完成后自动生成作业记录，单价从基地台账自动回填。

---

### 5. 📝 作业记录管理

记录农事作业的实际执行情况和成本。

**记录内容**
- 基本信息：日期、类型（自己作业/外包）、分区、作物、作业项目
- 人员：人数、名单、工时、工资
- 工具：名称、来源、工时、单价、合计
- 设备：名称、来源、工时、单价、合计
- 物资：名称、规格、数量、单位、单价、合计
- 外包：项目名称、计价方式、总价

**自动成本回填**
- 从派工单生成作业记录时，工具/设备/物资单价自动从基地台账匹配回填
- 成本汇总自动计算

---

### 6. 💰 成本分析

对比计划预算与实际成本，支持全维度分析。

- 计划预算总额 vs 实际成本总额
- 分项对比：人工 / 设备 / 工具 / 物资 / 外包
- 差异分析：超支/节约金额和百分比

---

### 7. 🏠 基地管理

园区基础信息管理底座，为派工单和作业记录提供数据支撑。

| 子模块 | 管理内容 |
|--------|---------|
| 基本信息 | 基地名称、区域、海拔、气候、土壤、灌溉方式 |
| 地块信息 | 编号、名称、面积、土壤、灌溉、设施、状态、作物、责任人 |
| 人员信息 | 工号、姓名、岗位、用工类型、入职日期、**日薪**、技能、负责地块 |
| 工具台账 | 编号、名称、规格、品牌、数量、存放位置、保管人、状态、使用效率、成本 |
| 设备设施 | 编号、名称、型号、分类、购置日期、原值、使用年限、状态、维护成本 |
| 物资库存 | 编码、名称、类别、规格、库存量、安全库存、存放位置、有效期、供应商、单价 |

## 🔄 业务数据流

```
生长模型（品种·指标·作业·物候期）
    │
    ├──→ 种植计划（选作业·配资源·定日期）
    │        │
    │        ├──→ 派工单（现场执行）
    │        │        │
    │        │        └──→ 作业记录（成本归档）
    │        │
    │        └──→ 计划预算 ──────────────→ 成本对比分析
    │
    ├──→ 数据采集（录入实测值·实时判定）
    │        │
    │        └──→ 异常指标 → 调整措施建议
    │                 │
    │                 └──→ 派工单（采集驱动）
    │                          │
    │                          └──→ 作业记录
    │
    └──→ 基地管理（地块·人员·工具·设备·物资）
             │
             └──→ 作业记录单价自动回填
```
